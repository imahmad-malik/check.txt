# Bixie Haircut homepage downloads

These are HTML design previews; no WordPress theme/plugin is included.

- **Homepage-HTML.zip** contains only **Bixie-Homepage.html**, the compact single-file homepage. Extract it and open the HTML in your browser. CSS, photos, fonts, JavaScript and the silent motion study are embedded. The smaller images and video preserve the design with lower resolution.
- **bixie-preview.zip** contains the same compact entry plus editable source.html, optimized full quality assets, CSS, JavaScript, fonts/licenses, research and documentation. Extract the complete ZIP and open index.html. Open source.html with its bundled sibling files to review full quality.
- **Bixie-Homepage.html** is the HTML itself. GitHub's raw HTML endpoint displays source text, so use the first ZIP link to trigger a file download.

Desktop/mobile browser checks passed, including all images/fonts, search, saved looks, comparison, video and motion. The chat file viewer did not provide working downloads, which is why these files are supplied through this repository branch. See the package validation report for browser and production limits.

SHA-256 values and sizes are in download-sha256.json.
