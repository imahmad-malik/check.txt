# Original media and release status

The current media manifest contains **one real generated original**. It is a front-three-quarter resolution probe, not a completed gallery look. Its PNG source and full-aspect WebP are both **1312 × 1199**. The WebP was encoded with ffmpeg at quality 95 without resizing, cropping, sharpening or upscaling.

The generator has no exposed pixel-size parameter. An explicit request for the highest native size and native 8K produced the dimensions above. No native 8K image has been produced or verified. The requested native 8K publication requirement remains pending a user decision; the `native_8k` value must remain false for this probe regardless of that decision.

`manifest.json` records actual files only. `generation-plan.json` contains **planned requests only**: 22 collections, seven complete looks per collection, three separately generated views per look, plus 25 separate homepage images. That is 154 planned looks, 462 planned gallery photographs and 25 planned homepage assets. A three-angle look is one look. A collage panel, duplicate file, crop or resize is not a new original. The catalog's separate 440-look expansion remains future planning and is not part of the current generation queue.

`old-source-audit.json` records the strict review of all 26 previous sources. None of the old haircut photographs passes all new high-collar, loose-clothing and framing requirements. The tools still life contains no person, but it is not a haircut-gallery photograph. All legacy originals remain preserved outside this package and are not imported here.

For generation, inspect each newly generated front image before using it as a reference for side and back requests. Keep the same fictional adult, haircut geometry, hair colour, high opaque loose collar, light and background across the three distinct tool-provided output files. Reject exposed neckline or chest, low/open/sleeveless clothing, fitted torso contours, clipped hair, inadequate breathing room, deliberate blur, inconsistent angle identity, or an inaccurate haircut category. Never count a composite or cropped source as three images.

Record the exact tool arguments, actual source dimensions, PNG source hash, encoded display hash, intended collection/look/angle, and direct review result. Preserve complete source aspect ratios when encoding and displaying. Use WordPress full images rather than hard-cropped thumbnail sizes. Keep a look draft until all three views pass; keep a collection draft until it has at least seven complete looks and 21 distinct approved photographs. If the user accepts available native dimensions, update the explicit publication requirement while preserving each record's true dimensions and false native-8K flag.
